Pre-warm Mechanics

        

          Phase 1 — Synthetic runs immediately at startup. Each region is populated with 
          physically-plausible values from the analytical ocean model. These tiles are pinned in the page table 
          and will never be evicted by LRU. Status: synthetic


          Phase 2 — Real kicks off in the background if Copernicus credentials are 
          present. Real data replaces synthetic data seamlessly, status upgrades to 
          real


          Pinned pages are excluded from the LRU eviction algorithm so that heavy 
          exploration of remote ocean areas never purges the Indian Ocean home region.
